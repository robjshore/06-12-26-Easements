Galleria Schedule ‘A’ — Easements: who grants what to whom

The Galleria project is one mixed-use development split into four parts that share the same structure: the Residential Condo, the Parking, the Commercial units, and the future Blocks 1 & 3. Because they overlap physically, each part must grant the others legal rights (easements) — to pass through, run services, draw structural support, and so on. This grid maps every one of those rights.

How to read this grid

  1. Each row is the parcel that is burdened — it gives up a right (the “servient” land).
  2. Each column is the parcel that is benefited — it receives the right (the “dominant” land).
  3. The big number in a cell is how many easements run that way. The coloured tags show what kinds of rights they are.
  4. Click any cell to read, in plain English, exactly what each easement allows.
Example — the cell in row Residential Condo, column Parking means: “The Residential Condo must allow the Parking parcel to do these things on/through the Condo’s land.” If both that cell and its mirror (row Parking, column Condo) are filled, the right is reciprocal — granted both ways.
Rows = BURDENED parcel (gives up the right)  •  Columns = BENEFITED parcel (receives the right). Empty cell = no easement that direction.
👈 Click any filled cell in the grid to see, in plain English, every easement that runs between those two parcels.
